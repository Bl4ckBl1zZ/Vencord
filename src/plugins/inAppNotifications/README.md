# In App Notifications

Shows message notifications in the top-right while Discord is focused. Notifications that arrive together are stacked below one another with independent timers. Each card includes the sender, a meaningful message or embed preview, and the server/channel context. Click the card to open the conversation, hover to pause its timer, use the close button to dismiss it, or right-click for Discord's message menu.

The plugin follows Discord's own notification and mute rules, skips the channel already on screen by default, and does not duplicate notifications while Discord is unfocused. Attachments, files, stickers, Discord embeds, inline replies, and recent reactions can be changed in the plugin settings. A preview button is included so the layout can be tested immediately.
