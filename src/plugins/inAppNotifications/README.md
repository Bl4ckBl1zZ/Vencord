# In App Notifications

Shows message notifications in the top-right while Discord is focused. Each compact card includes the sender, a two-line preview, and the server/channel context. Click the card to open the conversation, hover to pause its timer, use the close button to dismiss it, or right-click for a quick dismissal.

The plugin follows Discord's own notification and mute rules, skips the channel already on screen by default, and does not duplicate notifications while Discord is unfocused. Message previews and bot notifications can be changed in the plugin settings. A preview button is included so the layout can be tested immediately.
